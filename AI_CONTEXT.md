# Projeto: Precificador SaaS

Este projeto é um sistema SaaS para cadastro e precificação de produtos.

## Objetivo
Permitir cadastrar produtos, armazenar no banco PostgreSQL e calcular preços de venda.

## Tecnologias usadas
- Frontend: HTML, CSS e JavaScript
- Backend: Node.js com Express
- Banco de dados: PostgreSQL

## Estrutura do projeto
- client/: telas do sistema
- server/: backend, rotas, banco e regras de negócio

## Funcionalidades atuais
- cadastro de produtos
- listagem de produtos
- integração entre frontend e backend
- armazenamento em banco PostgreSQL

## Funcionalidades desejadas
- paginação de produtos
- busca de produtos
- importação de XML
- cálculo automático de preço
- dashboard com indicadores

## Escala esperada
O sistema deve suportar entre 3.000 e 15.000 produtos.
