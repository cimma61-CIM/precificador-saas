# AGENTS

Este projeto é um SaaS de precificação.

## Tecnologias
- Backend: Node.js + Express
- Banco: PostgreSQL
- Frontend: HTML + CSS + JS

## Estrutura
client/ → interface
server/ → backend

## Regras
- Sempre usar async/await
- Queries SQL devem ser otimizadas
- Listagens devem usar paginação LIMIT + OFFSET
- Evitar duplicação de código

## Escala
O sistema deve suportar até 15000 produtos.
