# Documentacao Legada

Esta pasta preserva arquivos de documentacao e orientacao anteriores a reorganizacao atual.

Objetivo:

- evitar perda de contexto historico;
- manter rastreabilidade das anotacoes antigas;
- permitir comparacao entre o planejado e o implementado.

Observacao:

- alguns arquivos legados descrevem funcionalidades futuras ou estruturas de banco que ainda nao correspondem exatamente ao estado atual do codigo.
