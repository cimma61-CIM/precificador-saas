# Regras do Projeto

## Regras gerais
- usar JavaScript no backend
- usar async/await
- evitar callbacks desnecessários
- manter código simples e organizado
- comentar apenas quando realmente necessário

## Backend
- separar rotas da conexão com banco
- usar Express
- manter queries SQL organizadas
- preparar o sistema para paginação e busca

## Banco de dados
- usar PostgreSQL
- não apagar dados existentes sem necessidade
- sempre considerar performance para muitos produtos

## Frontend
- manter layout limpo
- priorizar usabilidade
- preparar telas para grandes listas de produtos
